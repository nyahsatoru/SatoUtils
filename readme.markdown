# SatoAddon - A stupid utility. :>

A small Minecraft utility mod made for fun and convenience.

This is my first real project, so yeah... **I'm still kinda dumb at this.**
Some parts may be messy, weird, or break sometimes. I'm learning as I go and improving things along the way.

## Supported versions
- Minecraft 1.21.11
Support for other versions coming soon...

## Releases
https://github.com/nyahsatoru/SatoAddon/releases

## Features
- Sato Auto Sell - Automatically sells items from your inventory
- Sato Auto Loot - Automatically collects nearby loot
- Sato Mining - **Automated mining powered by a fork of Baritone**
